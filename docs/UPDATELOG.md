# Molecule Lab 업데이트 내역

## 2026-11-02

- GitHub Pages 자동 배포 워크플로를 준비했습니다.
- 3D 분자 조립대를 만들었습니다. 원자 서랍에서 H·C·N·O·Na·Cl을 놓고, 원자를 끌어 다른 원자에 붙이면 결합이 만들어집니다.
- 결합 도우미를 추가했습니다. 키보드나 터치만으로도 원자를 연결할 수 있고, 목표 분자를 고르면 올바른 결합 자리와 결합 차수를 안내합니다.
- 결합각과 극성 표시를 넣었습니다. 선택한 원자의 결합각을 3D에 표시하고, 결합 극성과 합성 극성 벡터를 화살표로 보여줍니다.
- 화학식 자동 판정을 넣었습니다. 현재 만든 분자의 화학식, 원자 수, 결합 수를 목표 분자와 비교해 완성 여부와 다음 할 일을 알려줍니다.
- 분자 도감 12종을 넣었습니다. 물, 이산화탄소, 메탄, 암모니아, 산소, 질소, 수소, 염화수소, 염화나트륨, 이산화황, 황화수소, 에텐을 한글 설명과 3D 구조로 볼 수 있습니다.
- 상태변화 무대를 만들었습니다. -20°C에서 120°C까지 온도를 바꾸며 고체·액체·기체 입자 배열과 상대 부피를 관찰하고, 입자 수를 최대 2,000개까지 비교할 수 있습니다.
- 반응 극장을 만들었습니다. 중화 반응과 염화은 앙금 생성 반응을 재생·일시정지·단계 이동·배속 재생으로 관찰할 수 있습니다.
- 분자 퀴즈를 만들었습니다. 3D 구조를 보고 이름을 맞히는 5문제 quiz와 점수·해설을 추가했습니다.
- 화면 전체를 '분자 표본실' 콘셉트로 다시 꾸몄습니다. 따뜻한 모래색 종이, 이끼색 실험대, 세리프 제목, 금빛 표본 표시를 사용했습니다.
- 하단 화학식 바를 항상 표시하고, 모바일에서는 5개 화면 탭과 조작 패널이 한 화면 폭에 맞도록 정리했습니다.
- 키보드 초점, 색 대비, 화면 읽기용 이름, 모션 줄이기 설정을 점검했습니다.
- 단위 테스트와 브라우저 테스트를 추가했습니다. 물 결합각 104.5°, 화학식 판정, 1,500개 입자 시뮬레이션, 반응 타임라인 완주, 도감·퀴즈 흐름, 접근성 검사를 확인합니다.
- 물의 밀도 모형을 바로잡았습니다. 4°C에서 밀도가 가장 크고, 얼음은 물보다 부피가 커서 물에 뜬다는 설명을 상태 화면에 넣었습니다.
- 화학식은 맞지만 모양이나 결합 차수가 틀리면 완성으로 인정하지 않습니다. 결합 차수 바꾸기, 원자가 사용량, 비공유 전자쌍 표시를 추가했습니다.
- 반응마다 알짜 이온식을 함께 보여줍니다.
- 실행 취소/다시 실행, 원자 복제, 이동·회전 모드, 시점 초기화, 결합 미리보기, 거리 측정을 조립대에 넣었습니다.
- 작업대를 JSON으로 저장·불러오기하고 공유 링크로 나눌 수 있습니다. 작업대는 자동으로 저장됩니다.
- 수업용 주소를 만들었습니다. 조립 목표, 온도·입자 수, 반응 장면, 도감, 퀴즈 문제, 학습지를 주소 하나로 열 수 있습니다.
- 인쇄용 학습지 화면을 만들었습니다. 관찰 기록과 모범 답안을 인쇄할 수 있습니다.
- 이온 도감 11종을 만들었습니다. 전하와 용해도, 관련 반응으로 바로 이동할 수 있습니다.
- 황산바륨과 아이오딘화납 앙금 반응을 추가했습니다. 반응 극장은 모두 4장면입니다.
- 퀴즈 오답을 비슷한 구조 위주로 내고, 최고 기록과 도전 횟수를 저장합니다.
